# Smart-Energy-Manager

An interactive command-line tool addressing UN Sustainable Development Goal 7: Affordable and Clean Energy.

🌍 The Problem
High energy consumption in households strains the electrical grid and increases carbon emissions. Many people are unaware of exactly how much power their daily appliances consume.

💡 Our Solution
The Smart Energy Manager allows users to input their daily appliance usage (AC, Fan, Lights, TV). The script calculates monthly energy consumption (in kWh), estimates the financial cost, and provides smart, automated recommendations to help users reduce their energy footprint.

🛠️ Technical Execution
Language: Python 3
Features:
Dynamic user input parsing
Algorithm for calculating kWh from wattage and hours
Conditional logic for customized energy-saving recommendations
🚀 How to Run the Code
Ensure you have Python installed on your computer.
Download or clone this repository.
Open your terminal or command prompt.
Run the following command:
python main.py
